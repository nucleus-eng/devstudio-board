It is empty of sequences on purpose.

| --- | --- |

Neither file is in `nucleus-eng/DNA`. Both need submitting there before this
DevNote publishes.

Neither file is placed here yet, because neither could be verified. Each copy
fetched from Drive is one byte smaller than Drive reports for it, and holds one
base fewer than its own `LOCUS` line declares. That may be a fault in the fetch
rather than in the file. See `gap-constructs-unverified` in `main.md`.

Place the confirmed files here once an author has checked the originals.
